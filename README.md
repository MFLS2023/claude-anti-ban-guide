1. **底座必须干净：** 严禁商业机场、机房节点；使用独享静态住宅 IP 或纯净自建，并确保在 `ip.net.coffee` 检测全绿无泄漏。
2. **环境彻底隔离：** 统一使用全中文指纹浏览器 **AdsPower**，原生切断 WebRTC UDP 泄漏，自动匹配时区与语言。
3. **电话拒绝廉价接码：** 推荐购买英国 giffgaff 实体卡（0 月租国内免费漫游收短信），或 sms-activate 欧美冷门区。

5. **坚决杜绝零对话秒充值：** 刚注册完先发 1~2 句正常对话，静置 12~24 小时养号建立基础真人信任，再去手机上付款升级。
